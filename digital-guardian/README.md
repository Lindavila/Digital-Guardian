# Digital Guardian

Android personal-safety prototype built with Kotlin and Jetpack Compose.

## Current MVP
- Protection status dashboard
- Trusted peers indicator
- Location status placeholder
- Hold-for-SOS prototype action
- Test alert action

## Planned production work
- Firebase Authentication and Firestore for users/trusted peers
- Firebase Cloud Messaging for peer push alerts
- Location permission + live emergency location sharing
- SOS cancellation/countdown and alert history
- Device-supported discreet hardware/accessibility shortcut research and implementation

> This prototype does not contact emergency services or send real alerts yet.
